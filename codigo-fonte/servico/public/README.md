# Logo da CNT

Por favor, adicione a logo da CNT nesta pasta com o nome `logo-cnt.png`

## Requisitos da imagem:

- **Nome do arquivo**: logo-cnt.png
- **Formato**: PNG (preferencialmente com fundo transparente)
- **Tamanho recomendado**: 200x60 pixels (ou proporção similar)
- **Qualidade**: Alta resolução para telas Retina

## Localização:

```
public/images/logo-cnt.png
```

A logo aparecerá:
- No topo da página de votação pública
- No topo da página de login
- No cabeçalho do painel administrativo

## Caso não tenha a logo ainda:

Você pode usar temporariamente uma logo placeholder criando um arquivo PNG simples ou texto.
